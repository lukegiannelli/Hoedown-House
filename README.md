# 🤠 The Hoedown House

Dallas–Fort Worth shows, honky-tonks, comedy, dance socials and nights out, with prices, drive times and what your night will cost. Centered on North Dallas, looking out ~120 miles.

**Live:** https://lukegiannelli.github.io/Hoedown-House/

- `index.html` – the app (installable: Share → Add to Home Screen)
- `events.json` – the show list, refreshed every morning by a scheduled Claude task
- `afters.json` – late-night spots for the Night Card (honky-tonks, KBBQ, karaoke, King Spa, ice houses…)
- `pool.json` – pool halls (from OpenStreetMap, via the "OSM pool halls" workflow)
- Ticketmaster prices need the repo secret `TM_API_KEY` (Settings → Secrets and variables → Actions).

A sister app of [The Show Shack](https://lukegiannelli.github.io/showshack/).
